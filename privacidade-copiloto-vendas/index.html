O que a extensão faz com os dados que você cadastra

Em linguagem direta, sem juridiquês de gaveta — pra você decidir com informação de verdade, não com uma promessa genérica de "seus dados estão seguros".

Última atualização: 2 de agosto de 2026 Versão da extensão: 2.47.0 Aplica-se a: extensão de Chrome "Co-piloto de Vendas — C&S Virtual" e à versão web equivalente
🔒

Resumo em uma frase: o Co-piloto roda inteiramente no seu navegador — não existe servidor nosso guardando ou vendo os dados dos seus leads. As únicas informações que saem do seu computador são as que você manda de propósito pra IA (Claude ou Gemini) gerar uma resposta, usando uma chave de API que você mesmo configura.

1

Onde os dados ficam

Em nenhum lugar além do computador de quem instalou a extensão. Tudo é gravado no armazenamento local do navegador (chrome.storage) — não existe um servidor do Co-piloto de Vendas recebendo, centralizando ou fazendo backup desses dados em algum lugar.

Se a extensão for desinstalada ou o computador trocado, os dados não acompanham automaticamente: eles simplesmente continuam onde estavam, porque nunca saíram dali. Cada profissional cadastrado tem seus próprios leads, histórico, funil, campanha e configurações, totalmente isolados dos demais.

2

O que guardamos

Só o que é necessário para o atendimento:

  • Dados de cada lead: nome, telefone, e-mail, CEP, data de nascimento, CPF, objetivo, notas e estágio no funil de vendas.
  • Histórico de mensagens coladas e respostas geradas por lead.
  • Configurações do negócio: funil de vendas, campanha ativa e o preço estimado por token (usado só pra calcular o custo de uso da IA).
  • Chaves de API (Anthropic/Google) configuradas por cada profissional.
  • Usuário/senha de acesso (principal e de equipe, se configurada), senha de cada perfil e o código de recuperação de cada um (o PIN, no caso do administrador) — nenhum deles em texto puro.
3

O que sai do computador — e quando

Sempre por decisão de quem está usando, nunca sozinho. Quatro ações chamam uma IA externa, cada uma enviando uma quantidade diferente de dado:

💬
"Gerar resposta" e "Sugerir abordagem ou follow-up"Enviam o nome do lead (ou da pessoa, na central de mensagens compartilhada), o objetivo/notas dele, o estágio no funil, o texto colado e, se preenchida, a informação adicional daquela resposta — ao provedor de IA escolhido (Claude, da Anthropic, ou Gemini, do Google), usando a chave de API que o próprio negócio configurou.
🔍
"Sugerir estágio com IA"Envia só o texto colado, nada mais (sem nome, objetivo, notas ou estágio) — sempre pelo nível gratuito do Gemini, mesmo que o provedor principal configurado seja outro.
🩺
"Health Monitor"É diferente das outras três: não envia nenhum dado de lead. Ao escolher um provedor, manda só uma mensagem fixa mínima ("oi") pra cada modelo daquele provedor, usando a chave de API já configurada, só pra medir se o modelo está respondendo e em quanto tempo.
Telefone, e-mail, CEP, data de nascimento e CPF nunca saem do computador — não fazem parte do que é enviado à IA, em nenhuma hipótese.

O conteúdo das conversas do WhatsApp Web não é lido pela extensão além do cabeçalho da conversa aberta (nome/telefone, só para localizar o lead certo). Colar uma mensagem para gerar resposta é sempre um gesto manual, nunca automático.

4

Como protegemos esses dados

  • Duas camadas de acesso: uma credencial geral de instalação (a "Área restrita", que pode ser trocada a qualquer momento pelo administrador — uma instalação que nunca fez essa troca continua com a senha padrão de fábrica e mostra um aviso persistente até ser alterada) e, depois, a senha individual de cada perfil.
  • Nenhuma senha em texto puro: hash PBKDF2-HMAC-SHA256 com 210 mil iterações e valor aleatório único por senha.
  • Bloqueio automático depois de 3 tentativas erradas seguidas, travando o campo por 60 segundos, em qualquer tela que peça senha.
  • Campos sensíveis cifrados com AES-256-GCM (CPF, e-mail, CEP, nascimento, notas, histórico de conversas e chaves de API) — ilegíveis sem a chave correta, não apenas escondidos da tela.
  • Código de recuperação próprio por perfil, mostrado uma única vez, no momento da criação ou última troca de senha.
  • Sessão expira sozinha depois de 30 minutos de inatividade.
  • Nunca duas abas mexendo nos mesmos dados ao mesmo tempo: uma cópia do painel aberta por engano é travada automaticamente, sem carregar nenhum dado.
  • Chaves de API só no computador de quem usa — nunca trafegam por nenhum servidor nosso, vão direto do navegador ao provedor de IA escolhido.
  • Restaurar um backup avisa antes de trocar suas chaves de API: se o arquivo escolhido tiver uma chave de API diferente da já configurada, um aviso específico aparece antes de confirmar.
5

Retenção e exclusão

  • Leads e respostas excluídos ficam recuperáveis por 30 dias antes de serem apagados definitivamente.
  • O log de sessões e ações, visível só para o administrador, fica guardado por até 90 dias.
  • Qualquer lead pode ser excluído em definitivo a qualquer momento, sem precisar esperar esse prazo.
  • Quem administra a instalação pode resetá-la por completo (todos os perfis e dados) quando quiser.
  • Backup e restauração permitem exportar ou apagar os próprios dados a qualquer momento — o controle é de quem usa.
6

Permissões usadas — e por quê

A extensão pede o mínimo de permissão possível pra funcionar. Cada uma existe por um motivo pontual, nenhuma é usada pra rastreamento:

💾
storage e unlimitedStorageGuardam leads, histórico, configurações e chaves de API dentro do próprio navegador (chrome.storage.local). unlimitedStorage só remove o teto padrão do Chrome, pra negócios com muito histórico não perderem dados — nada disso sai do computador por causa dessa permissão.
📋
clipboardReadPermite colar, com um clique, o texto de uma mensagem copiada do WhatsApp Web direto na caixa de colagem do Co-piloto — só é acionada quando você aperta o botão de colar, nunca lê a área de transferência sozinha.
🌐
Acesso a api.anthropic.com e generativelanguage.googleapis.comSão os dois únicos domínios externos que a extensão pode chamar — os provedores de IA (Claude e Gemini) escolhidos por você, usando a chave de API que você mesmo configura. Nenhum outro domínio é contatado.

A extensão não usa nenhuma permissão de leitura de aba, histórico de navegação, geolocalização ou identidade — só o necessário pra ler o cabeçalho da conversa aberta no WhatsApp Web e chamar a IA escolhida.

7

O que não fazemos

  • Não vendemos, alugamos nem compartilhamos dados com ninguém além do provedor de IA escolhido pelo próprio usuário — e só o mínimo necessário para gerar a resposta.
  • Não usamos publicidade, rastreamento de navegação nem analytics de uso.
  • Não automatizamos, interceptamos nem enviamos nada dentro do WhatsApp Web — cada envio é decidido por quem está usando.
  • Não usamos código remoto: todo o JavaScript da extensão está empacotado localmente, nada é carregado ou executado a partir de um servidor externo.
8

De quem é a responsabilidade

O Co-piloto de Vendas é uma ferramenta local — quem decide quais dados de cada lead cadastrar, e com qual base legal, é o negócio que usa a extensão, não quem a desenvolveu. Este texto descreve o que o software faz com os dados; obrigações legais do negócio que o utiliza (como avisar os próprios clientes sobre o uso de IA no atendimento, quando aplicável) continuam sendo dele, nos termos da LGPD (Lei 13.709/2018).

A extensão tem propósito único (apoiar o atendimento de vendas consultivas por WhatsApp com IA), não coleta dados para publicidade, não revende dados a terceiros e usa cada permissão do manifest.json estritamente para a função descrita nesta política — em linha com as Chrome Web Store Developer Program Policies.
