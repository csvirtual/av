Política de Privacidade

Última atualização: 27 de agosto de 2026 · Versão da extensão: 1.6.0

Resumo em 30 segundos

  • Nenhum dado sai do seu computador. Tudo fica salvo localmente no navegador, dentro do próprio perfil do Chrome onde a extensão foi instalada.
  • Não existe servidor. A extensão não faz nenhuma chamada de rede — não há backend, não há analytics, não há terceiros envolvidos.
  • Senhas nunca ficam em texto puro — são protegidas com hash criptográfico (PBKDF2).
  • Backups são criptografados com a senha que você escolhe (AES-256-GCM) — sem ela, o arquivo é ilegível.
  • Você é quem decide o que fazer com os dados — exportar, restaurar ou apagar tudo é sempre uma ação manual sua, nunca automática.
1

Quem é o responsável por este documento

A extensão Gestão de Loja — Estoque & Vendas é uma ferramenta de controle de estoque, vendas, caixa, clientes e financeiro voltada a lojas de material de construção, mercearias e mercados de bairro. Este documento explica que dados a extensão processa, onde ficam guardados, e quais são os direitos de quem usa o sistema e de quem tem seus dados cadastrados nele.

2

Que dados o sistema processa

Para funcionar, o sistema guarda os seguintes tipos de dado, todos inseridos manualmente por quem usa a extensão:

  • Dados da loja — CNPJ, razão social, endereço, telefone, e-mail.
  • Dados de quem usa o sistema (administrador e vendedores) — nome, nome de usuário e senha (guardada como hash, nunca em texto puro).
  • Dados de clientes da loja — nome, telefone, endereço, CPF/CNPJ (opcional), histórico de compras e de fiado, saldo de pontos de fidelidade (se o programa estiver ativo).
  • Dados de fornecedores — nome, contato, pedidos de compra.
  • Dados de entrega (carreto) — endereço de entrega (pode ser diferente do endereço cadastrado do cliente) e nome de quem faz a entrega, quando informado — que pode ser alguém sem cadastro de usuário no sistema.
  • Dados operacionais — produtos, estoque, vendas, pagamentos, movimentações de caixa, contas a pagar/receber, log de ações realizadas no sistema.

Nenhum desses dados é coletado para fins de análise, publicidade ou qualquer uso além do funcionamento do próprio sistema de gestão.

3

Onde os dados ficam guardados

Tudo é armazenado localmente, usando o IndexedDB do navegador — um banco de dados que vive dentro do perfil do Chrome onde a extensão está instalada, no computador da loja. A extensão também usa o chrome.storage para um punhado de dados pequenos e de curta duração: a sessão de quem está logado no momento (apagada ao fechar o navegador); o horário da última ação na tela, usado só para encerrar a sessão automaticamente após 30 minutos sem uso; um crédito de troca pendente de uso na próxima venda, quando existir; um registro temporário indicando que a extensão está aberta, usado só para impedir que ela opere em mais de uma aba do navegador ao mesmo tempo; o histórico de tentativas de senha incorretas, usado só para o bloqueio temporário do campo de senha; e a preferência de aparência (claro/escuro).

Não existe nenhum servidor, nuvem ou serviço externo envolvido. A extensão não faz nenhuma chamada de rede — isso pode ser conferido diretamente no código-fonte, que não contém nenhuma linha de comunicação com a internet.

4

Com quem os dados são compartilhados

Com ninguém. A desenvolvedora da extensão não tem acesso a nenhum dado inserido no sistema — não existe um canal técnico pelo qual isso seria sequer possível, já que nada é enviado para fora do navegador de quem instalou. Os dados só saem do computador se a própria loja optar por exportar um backup e movê-lo manualmente para outro lugar (um pendrive, um e-mail para si mesma, etc.) — uma ação sempre deliberada, nunca automática.

5

Segurança

  • Senhas de login são protegidas com PBKDF2 (150.000 iterações, salt único por usuário) — nunca gravadas em texto puro.
  • Backups exportados são criptografados com AES-256-GCM, chave derivada da senha escolhida na hora da exportação. Sem essa senha, o arquivo é ilegível — inclusive para a própria desenvolvedora.
  • A sessão de quem está logado expira automaticamente após 30 minutos sem uso, e o campo de senha bloqueia temporariamente após tentativas incorretas seguidas.

Como todo o dado vive no computador da loja, a segurança física desse computador (e de quem tem acesso a ele) faz parte da proteção geral dos dados — a mesma lógica de qualquer sistema local, como uma planilha ou um banco de dados instalado na máquina.

6

Por quanto tempo os dados ficam guardados

Os dados permanecem no IndexedDB indefinidamente, até que a loja decida excluí-los — seja removendo um cadastro individual (ex.: excluir um cliente ou produto) pela própria interface do sistema, seja desinstalando a extensão ou limpando os dados do perfil do Chrome, o que apaga tudo de uma vez. Não existe exclusão automática por tempo.

7

Responsabilidade sobre os dados de clientes (LGPD)

O sistema guarda dado pessoal de clientes da loja (nome, telefone, endereço, histórico de fiado), o que sujeita esse uso à Lei Geral de Proteção de Dados (LGPD). É importante deixar claro: quem é o controlador desses dados — o responsável legal perante a LGPD — é a loja que opera o sistema, não a desenvolvedora da extensão, que apenas fornece a ferramenta e não tem acesso, custódia ou qualquer forma de processamento sobre esses dados.

Recomendamos que cada loja que usa o sistema informe seus próprios clientes sobre a coleta desses dados, conforme exigido pela LGPD. A própria extensão ajuda de duas formas: a tela Ajuda → "Privacidade e LGPD" traz um modelo de aviso de privacidade pronto para imprimir ou entregar ao cliente, preenchido automaticamente com o nome da loja; e a tela Dados da loja tem um campo opcional para cadastrar o nome e contato do Encarregado de Dados (DPO) da loja, caso ela tenha um.

8

Permissões que a extensão solicita

PermissãoPara que é usada
storageGuardar os dados pequenos e de curta duração listados na seção 3 (sessão de login, timeout de inatividade, crédito de troca pendente, bloqueio de aba única, tentativas de senha, preferência de aparência) — os dados de negócio em si (vendas, estoque, clientes etc.) usam o IndexedDB do navegador, que não exige nenhuma permissão do manifesto.

Nenhuma outra permissão é solicitada — não há acesso a outras abas, histórico de navegação, câmera, localização ou rede.

9

Seus direitos

Como titular de dados cadastrado num sistema que usa esta extensão (por exemplo, como cliente de uma loja que a utiliza), você pode solicitar diretamente à loja — controladora dos seus dados — acesso, correção ou exclusão das suas informações. Como a loja tem controle total sobre o sistema (os dados vivem no computador dela), ela consegue atender esses pedidos diretamente pela própria interface do sistema.
